MPI_Scatter is more memory-efficient than MPI_Bcast because each process
receives only the data chunk it needs instead of receiving the complete
array. Execution times may vary between runs because the programs are very
short and communication overhead and system load can affect the results.


3. Thinking Question

MPI_Scan should be used when each process needs a cumulative result up to
its own rank instead of every process receiving the same global result.

For example, in a parallel prefix-sum calculation, each process can calculate
the sum of its own chunk and MPI_Scan can provide the sum of all chunks up to
that process. The value before the current process can then be used as a
global offset for its local prefix sums.

MPI_Allreduce would not be suitable for this case because it gives every
process the same final global total.
